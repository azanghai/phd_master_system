# 博士工作台操作说明

这份文档写给日常使用者，重点说明如何打开工作台、记录学术与生活事务、同步数据和备份恢复。界面中的按钮名称可能会随版本微调，操作时以当前页面显示为准。

## 1. 快速开始

### 1.1 打开方式

你可以用三种方式使用博士工作台：

- 桌面端：运行或安装 Tauri 桌面应用，适合长期使用和本机数据保存。
- 静态页面：打开 `app/index.html`，适合快速查看和本地测试。
- HTML 同步入口：运行 `npm run html:dev` 后打开终端中显示的本地地址，适合在浏览器里使用坚果云同步。
- Android 端：使用 Capacitor/Android 构建出的 APK，适合移动端记录。

如果你只是想先体验功能，优先打开桌面端或 `app/index.html`。如果要在普通浏览器里同步坚果云，不要直接双击 HTML 文件，改用 `npm run html:dev`。如果页面样式或图标显示异常，先运行一次 `npm run prepare:static`，让本地静态资源重新生成。

### 1.2 第一次使用建议

1. 打开工作台后，先进入左侧 `设置`。
2. 在 `角色与模块中心` 选择适合自己的角色预设，例如通用研究者、硕士研究者或博士研究者。
3. 检查模块开关，确认是否需要启用 `投稿`、`导师`、`复盘`、`报销` 等模块。
4. 回到 `今日` 页面，从 `快速记录` 新增第一条任务。
5. 如果需要多设备使用，再配置 `坚果云 WebDAV` 同步。

## 2. 页面导航

左侧导航是主要入口。移动端可以点击顶部菜单按钮打开导航。

| 页面 | 用途 |
| --- | --- |
| `今日` | 查看今日主线、当前时间线、快速记录和近期提醒。 |
| `提醒` | 聚合任务、项目、论文、投稿和导师跟进的近期节点。 |
| `任务` | 查看今日执行、专注计时器、专注时间线和当日日程。 |
| `日程` | 管理项目、任务总表，并把任务排入具体时间块。 |
| `论文` | 记录论文信息、里程碑、章节进度和论文推进日志。 |
| `投稿` | 管理投稿项目、投稿阶段、推进日志和 Markdown 导出。 |
| `打卡` | 记录上午、下午、晚上工作段，以及请假情况。 |
| `习惯` | 记录早睡早起、运动、饮食、体重和自定义习惯。 |
| `导师` | 记录导师沟通、承诺、反馈、下一步动作和待追踪事项。 |
| `复盘` | 写每日复盘、明日优先任务，并生成任务。 |
| `报销` | 记录待报销、上传票据、确认已报销。 |
| `洞察` | 查看任务、打卡、习惯、论文、投稿等统计图表。 |
| `设置` | 管理角色模块、JSON 备份、坚果云同步和数据概览。 |

顶部或今日页的 `搜索` 可以搜索任务、项目、投稿、导师记录和提醒。也可以使用 `Ctrl + K` 或 `Cmd + K` 打开全局搜索。

## 3. 高频操作流程

### 3.1 新增任务

最快路径：

1. 进入 `今日`。
2. 在 `快速记录` 输入任务名称，例如“回复审稿意见”。
3. 点击 `新增任务`，或按 `Enter`。
4. 新任务会进入任务系统，后续可在 `任务` 或 `日程` 中继续安排。

更完整路径：

1. 进入 `日程`。
2. 在 `新建任务` 中填写任务名称。
3. 选择所属项目、紧急程度、状态和截止日期。
4. 点击 `新增任务`。

提示：如果刚新建了项目，下一条任务会默认归入刚创建的项目。

### 3.2 新建项目

1. 进入 `日程`。
2. 在 `新建项目` 中填写项目名，例如“Chapter 3 图表整理”。
3. 填写完成结果，例如“交出可发导师的版本”。
4. 选择项目分类、开始日期和截止日期。
5. 点击 `新增`。

保存后，该项目会自动成为当前选中的项目，方便马上继续添加任务。

### 3.3 把任务排入日程

1. 进入 `任务` 页面。
2. 在 `今日日程` 区域选择日期。
3. 展开 `时间块规划：把任务放进日程`。
4. 在任务下拉框中选择任务。
5. 填写开始时间和结束时间；如果任务有预计时长，选择开始时间后会自动推算结束时间。
6. 可以改写时间块标题。
7. 点击 `排入日程`。

排入后，下方时间线会显示对应时间块。点击时间线里的时间块可以修改。

### 3.4 开始和结束专注

1. 进入 `任务` 页面。
2. 如果要绑定任务，先在今日任务中点击 `开始`。
3. 在 `专注计时器` 中填写本次专注主题，也可以留空自动读取当前任务。
4. 点击 `开始专注`。
5. 完成后点击 `结束专注`。
6. 如果本次计时不需要保留，点击 `放弃本次`。

需要补录时，展开 `手动补录`，填写日期、主题、开始时间和结束时间，再点击 `添加专注记录`。

### 3.5 工作打卡

1. 进入 `打卡`。
2. 按实际时段点击上午、下午或晚上的 `到岗`。
3. 在弹出的心情选择中选择当前状态。
4. 离岗时点击同一时段的 `离岗`，再选择心情。
5. 如果有请假，选择请假类型后点击 `记录请假`。

如果忘记结束某个工作段，可以点击 `补全今天未结束时段`。如果请假记录误填，可以点击 `清空今日本日请假记录`，这个操作会清掉当天请假记录。

### 3.6 记录论文推进

1. 进入 `论文`。
2. 在 `论文信息` 中填写题目、目标日期、阶段版本和备注，点击 `保存信息`。
3. 在 `论文里程碑` 中添加关键节点，例如“预答辩 PPT 定稿”。
4. 在 `论文章节` 中添加章节，维护进度和状态。
5. 在 `论文推进日志` 中填写日期、类型、分钟、字数和备注。
6. 点击 `添加日志`。

论文日志会参与 `洞察` 中的论文投入统计。

### 3.7 推进投稿项目

1. 进入 `投稿`。
2. 点击 `添加投稿项目`。
3. 填写题目、期刊/会议名、截止日期、阶段、类型和备注。
4. 点击 `保存项目`。
5. 在 `投稿流程看板` 中查看项目所在阶段。
6. 点击项目卡片上的 `推进` 可以进入下一阶段。
7. 在 `投稿推进日志` 中选择项目，填写日期、类型、分钟和日志内容。
8. 点击 `添加推进日志`。

投稿日志输入框支持 `Ctrl + Enter` 或 `Cmd + Enter` 快速保存。

### 3.8 记录导师沟通

1. 进入 `导师`。
2. 选择日期，或点击 `查看今天`。
3. 填写沟通状态、沟通渠道、压力、预期清晰度。
4. 记录主题、准备好的证据、希望导师给的支持、当前卡点、导师反馈。
5. 在 `防忘管理` 中记录导师说过的话、承诺、计划和下次核对日期。
6. 在 `下一次跟进动作 / 时间` 写下你要做的下一步。
7. 点击 `保存记录`。

如果下一步需要进入任务系统，点击 `手动加入任务总表`。导师记录中的多行输入支持 `Ctrl + Enter` 或 `Cmd + Enter` 保存。

### 3.9 写复盘并生成明日任务

1. 进入 `复盘`。
2. 选择日期，或点击 `查看今天`。
3. 选择能量状态，并填写能量管理备注。
4. 填写今日核心成果、未完成与拖延分析、学术洞见、障碍与对策。
5. 在 `明日优先任务` 填写 1 到 3 条任务。
6. 点击 `保存复盘`。
7. 如果要把明日优先写入任务系统，点击 `手动加入明日优先任务`。

复盘多行输入支持 `Ctrl + Enter` 或 `Cmd + Enter` 保存。点击 `下载 Markdown` 可以导出当天复盘内容。

### 3.10 记录报销

1. 进入 `报销`。
2. 在 `待报销` 中填写报销内容和总金额。
3. 选择发票文件，支持多选。
4. 点击 `新增待报销`。
5. 报销完成后，在待报销列表中点击 `完成报销`。
6. 填写完成日期、项目号，选择报销凭证。
7. 点击 `确认报销`。

## 4. 数据管理

### 4.1 数据保存在哪里

工作台会把数据保存在浏览器本地缓存中；在桌面端环境中，也会写入数据文件 `workspace-data.json`。你可以在 `设置` 的 `当前存储状态` 中查看数据大小和数据文件路径。

### 4.2 导出 JSON 备份

1. 进入 `设置`。
2. 点击 `导出 JSON 备份`。
3. 保存生成的 JSON 文件。

建议在大规模整理、同步前、清空数据前都先导出一次 JSON 备份。

### 4.3 导入 JSON 数据

有两种导入方式：

- 点击 `导入 JSON 文件`，选择备份文件。
- 把 JSON 内容粘贴到 `JSON 预览` 文本框，点击 `导入这段 JSON`。

注意：导入会用导入内容替换当前工作台数据。导入前建议先导出当前数据备份。

### 4.4 清空全部数据

`清空全部数据` 会删除当前本地数据并重新加载页面。这个操作不可撤销。点击前请确认已经导出 JSON 备份，或者确认坚果云中已有可恢复的数据。

## 5. 坚果云同步

坚果云同步使用 WebDAV。你需要准备：

- 坚果云账号。
- 坚果云第三方应用密码。
- WebDAV 地址，默认是 `https://dav.jianguoyun.com/dav/`。

桌面端和 Android 端可以直接同步。普通浏览器会拦截坚果云 WebDAV 的跨域请求，所以 HTML 版需要通过 `npm run html:dev` 打开；这个命令会启动一个只绑定本机的同步代理。

### 5.1 配置同步

1. 进入 `设置`。
2. 找到 `云同步设置`。
3. 在 `WebDAV 地址` 中保留默认地址，或填写自己的地址。
4. 填写坚果云账号。
5. 填写第三方应用密码。
6. 点击 `验证连接`。
7. 验证通过后点击 `保存配置`。

### 5.2 手动同步

- 点击 `立即同步`：执行一次智能同步。
- 点击 `仅上传本地到云端`：用本地数据覆盖/更新云端数据。
- 点击 `仅下载云端到本地`：用云端数据恢复到本地。

注意：

- `仅上传本地到云端` 适合你确认本机数据是最新版本时使用。
- `仅下载云端到本地` 会把云端数据应用到本机，使用前建议先导出当前本地 JSON 备份。

### 5.3 自动同步

勾选 `自动同步` 后，工作台会在数据修改后约 5 秒尝试同步。如果同步失败，会自动拉长重试间隔。

### 5.4 首次同步模式

首次同步时，系统会根据本地和云端是否已有数据判断模式：

- `首次模式：下载云端`：本地为空、云端有数据。
- `首次模式：上传本地`：本地有数据、云端为空。
- `首次模式：双向合并`：本地和云端都有数据。
- `首次模式：初始化空仓`：本地和云端都没有数据。

### 5.5 冲突和智能合并

如果本地和云端都改过同一类数据，同步会尝试智能合并，并在 `冲突备份` 和 `查看冲突/错误日志` 中显示处理结果。无法自动判断的字段会暂时保留本地值。

如果你不确定冲突结果是否正确：

1. 先点击 `导出 JSON 备份` 保存当前状态。
2. 打开 `查看冲突/错误日志`。
3. 根据实际情况选择 `保留本地`、`使用云端` 或 `重新智能合并`。

## 6. 常见问题

### 6.1 看不到某个模块

进入 `设置`，检查 `角色与模块中心` 中的模块开关。某些模块会根据角色预设默认隐藏，例如投稿、导师、复盘或报销。

### 6.2 同步失败怎么办

先检查：

1. 坚果云账号是否正确。
2. 是否使用第三方应用密码，而不是网页登录密码。
3. WebDAV 地址是否为 `https://dav.jianguoyun.com/dav/`。
4. 网络是否可用。

然后点击 `验证连接`。如果仍失败，打开 `查看冲突/错误日志` 查看具体错误。

### 6.3 误删或误导入数据怎么办

如果刚做过 JSON 备份：

1. 进入 `设置`。
2. 使用 `导入 JSON 文件` 或 `导入这段 JSON` 恢复。

如果开启了坚果云同步，并且云端仍是正确版本，可以使用 `仅下载云端到本地`。执行前建议先导出当前本地 JSON，避免二次覆盖。

### 6.4 移动端显示拥挤怎么办

移动端使用顶部菜单打开导航。表格类内容可能需要横向滚动，尤其是项目列表和任务总表。优先使用 `今日`、`任务`、`打卡`、`导师`、`复盘` 这些更适合移动端的入口。

### 6.5 图标或样式不显示怎么办

运行：

```bash
npm run prepare:static
```

这会重新生成 `app/index.html`、Tailwind CSS 和本地 Font Awesome / Chart.js 资源。

### 6.6 是否支持在线账号、多用户协作

当前工作台不提供在线账号体系，也不提供多人实时协作。坚果云同步用于个人多设备数据同步，不等同于在线协同编辑。
